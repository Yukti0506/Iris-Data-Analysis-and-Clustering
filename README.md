# Iris Data Analysis and Clustering

This repository contains three machine learning assignments based on the Iris dataset.

## Topics Covered

- K-Means Clustering
- Principal Component Analysis (PCA)
- Data Standardization
- Data Visualization
- Cluster Evaluation

## Files

- `Iris.csv` - Dataset
- `k_meanAssignment1_1.ipynb` - K-Means clustering
- `PCAAssignment1_2.ipynb` - PCA analysis
- `Iris_Flower_Clustering_Project.ipynb` - Complete project

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
